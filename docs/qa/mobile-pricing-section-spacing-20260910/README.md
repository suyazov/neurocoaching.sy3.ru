# Единые мобильные интервалы перед блоками с ценами

10 сентября 2026. Исправлено, опубликовано и повторно проверено на трёх production-страницах в теме 1.0.27.

Клиент попросил сделать зелёный интервал перед заголовком `Services` больше розового интервала перед первой ценовой карточкой и применить одну геометрию на About, Career и Neurocoaching. Извлечённые координаты нативных 320px PSD дают диапазон53–58px сверху и29–40px снизу. С учётом более позднего требования об одинаковых значениях приняты общие55px и35px.

| Career | 55px / 23px | 55px / 60px | 55px / 35px |
