# Career — отступы фиолетового блока Stand out

6 сентября 2026. **Исправлено и проверено на staging, не опубликовано.** Включено в ожидающую публикации1.0.24 вместе с Neuro hero spacing.

Владелец отметил три промежутка в примере макета: первый абзац → зигзаг; зигзаг → второй абзац; второй абзац → разделительная линия. Все должны быть равными.

Причина дефекта:420px минимальной высоты мобильной панели плюс унаследованный `margin-top:auto` последнего абзаца. Свободное место растягивало зазор после зигзага в зависимости от ширины/переносов текста.

| Промежуток, 430 CSS px | Production1.0.23 | Staging1.0.24 |
|---|---:|---:|
| До зигзага | 32 | 32 |
| После зигзага | 66.625 | 32 |
| До линии | 28 | 32 |

На320/375/390/430 staging даёт32/32/32px, без ошибок геометрии. Отступ перед линией считается до верхней границы2px псевдоэлемента. Внешний заголовок и Help-блок не редактировались. Desktop1440: координаты, размеры и шрифты измеренных элементов совпадают с production.

[До / staging, одинаковая ширина430px](comparison.webp). JSON-замеры всех ширин лежат рядом. В `mobile-geometry.js` добавлены отдельные проверки всех трёх расстояний. Проверка production до публикации намеренно не проходит — это демонстрирует, что тест обнаруживает дефект, а не подтверждает старый результат по умолчанию.

Публикация по-прежнему требует повторной авторизации WordPress, свежего полного бэкапа и повторных live-проверок. Никаких изменений production в этом проходе не сделано; цена/контент/JS/PHP не менялись.
