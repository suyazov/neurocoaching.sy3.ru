В сообщении названа Career, но текст, букет и профильная ссылка на скриншоте относятся к `/neurocoaching/`. Последующий пример отмечает пять равных промежутков. Это уточнение имеет приоритет над прежними индивидуальными PSD-отступами. Удалённая строка Neurointegration coaching не возвращается.

## Причина пропуска и исправление проверки

В CSS оставалось отдельное мобильное правило с48px после первого абзаца. При прошлой приёмке первого экрана проверялись изображения, типографика и ширина, но внутренние интервалы не были отдельно зафиксированы в проверке. Визуальный проход также пропустил эту разницу. Предыдущее утверждение о проверенном первом блоке было слишком широким.

Теперь `mobile-geometry.js` измеряет и проверяет **каждый из пяти** промежутков. Проверка текущего production намеренно показывает ошибки, а staging проходит. Это не доказательство готовности всех остальных отступов сайта: область этой правки ограничена показанным hero-блоком.

Все пять отступов используют один CSS-токен32px внутри мобильного media query. Убраны конфликтующий48px и добавочный верхний отступ кнопки; кнопка становится блочным flex-элементом без лишнего места для текстовой базовой линии. Стили десктопа не изменены: сравнение1440px даёт прежние18/31/55px между h1/абзацами/кнопкой и те же шрифты.
