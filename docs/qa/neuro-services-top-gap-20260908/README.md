# Neurocoaching — отступ перед Services

8 сентября 2026. Исправлено, опубликовано и повторно проверено на `https://digitalbelka.com/neurocoaching/` в теме 1.0.26.

Клиентский скриншот показал, что мобильный заголовок `Services | Neurointegration` слился с предыдущим фиолетовым блоком. Причина — 52px отступ из мобильного PSD применялся только до ширины 360px; на более широких телефонах общий стиль `.site-services` обнулял верхний padding.

| Ширина, CSS px | Production 1.0.25 до правки | Staging 1.0.26 | Production 1.0.26 |
|---:|---:|---:|---:|
| 320 | 52px | 52px | 52px |
| 375 | 0px | 52px | 52px |
| 390 | 0px | 52px | 52px |
| 430 | 0px | 52px | 52px |

Отступ теперь задан для `.site-page .neuro-services` во всём мобильном диапазоне до 850px. `mobile-geometry.js` отдельно измеряет его и требует 52±1px.

Проверено в Chrome DevTools:

- staging и production: 320/375/390/430, отступ52px, две карточки и нет горизонтального переполнения;
- production430 визуально: между секциями присутствует ровное свободное поле, заголовок и первая карточка не пересекаются;
- desktop1440: section padding0, относительные координаты/размеры заголовка и первой карточки, а также typography полностью совпали с версией до правки;
- `/`, `/career-services/`, `/neurocoaching/` отвечают200 и используют тему Neurocoaching; на целевой production-странице нет ошибок/предупреждений в консоли.
