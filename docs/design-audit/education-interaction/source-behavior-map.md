# Education interaction source-behavior map

Source of truth: the six supplied PSDs, verified against their manifest SHA-256 values. The desktop source uses a semantic `View more` label followed by a long, thin right-arrow vector. The dedicated 320 px compositions omit that link and show a 213 px first certificate plus the left edge of the next certificate. That partial next card is the only mobile browsing affordance; there are no source arrow buttons, dots, or pagination.

The desktop `View more` control remains a same-page link to the immediately following credentials list. This is the existing interaction-map destination and is consistent with the source sequence: certificate strip, `View more`, then expanded qualification copy. Each target section is programmatically focusable so fragment navigation moves both scroll position and focus.
